How I work

Same steps,
every job

Whether it's a dead mailbox or a new store, the order doesn't change.

Log it

Write down exactly what's happening, on which machine or page, and since when.

Find the cause

Trace it to the real source before touching anything. Error codes, logs, data.

Fix it safely

Back up first, then change one thing at a time and confirm it worked.

Hand it over

Explain what was wrong in plain words and leave notes for next time.
